# Unfold

Understand. Verify. Practice.

## Overview

UNFOLD is an AI-powered study workspace that will eventually allow users to create study workspaces, upload PDFs and study material, process and search documents, ask AI questions grounded in their own material, view source/page citations, generate quizzes, and track learning progress.

## Current Status

Project foundation initialized.
Application features are not implemented yet.
